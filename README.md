# 通用支持与隐私页面

纯静态 HTML/CSS，无脚本、表单、数据库、外部字体或统计组件。公开页面不包含具体应用名称或运营主体名称。

## 文件

- `index.html`：技术支持、常见问题及公开反馈入口。
- `privacy.html`：醒目标注“尚未生效”的通用隐私政策草稿。
- `styles.css`：手机和桌面共用样式、键盘焦点和打印样式。

## 发布方式

在专用公开仓库根目录保存上述文件，将 Pages 的发布来源设为默认分支根目录。启用 HTTPS 后，以站点根地址访问支持页，以 `privacy.html` 访问草稿。不要把仓库代码浏览页或 Raw 文件地址当作网页地址。

公开反馈入口使用本仓库 Issues，需要 GitHub 账号。Issues 内容公开，不接收隐私申请或个人资料。私密联系方式目前未配置，正式提审前需补齐并验证可用。

## 正式使用前

- 核对具体应用及版本的适用范围；通用政策不能无差别覆盖不同运营主体或不同数据行为。
- 明确披露实际责任主体；本通用草稿不替代相关主体信息。
- 根据实际代码和第三方组件说明，填实数据项、用途、权限、接收方、保存期限和删除路径。
- 补齐私密联系渠道、未成年人保护、必要同意与请求处理流程。
- 由负责运营和合规的人员核对文本，确定生效日期后再发布正式政策。
- 保持政策、应用内入口、商店隐私问卷与真实行为一致。草稿状态不得直接用于正式上架。
- 未来更新先核对线上现行版本及最小差异，不用旧文件覆盖新版本。保留版本记录，避免一个共用 URL 的变更意外影响其他应用。
